# ADR-003: Runtime Persian/English Localization

  - **Status:** Superseded by ADR-012 (2026-08-03) — v1 ships fa-IR RTL only; retained hedges listed in ADR-012

  - **Date:** 2026-08-02

## Decision

Support runtime locale switching, feature-scoped translation resources, direction-aware design tokens, CSS logical properties, and explicit mixed-script handling.

## Consequences

  - Translation coverage is a CI quality gate

  - Custom components must test RTL and LTR

  - Clinical anatomy does not mirror with page direction

  - Gregorian/UTC remains canonical for interchange; Jalali is a required first-class presentation and input mode under ADR-005.

  - Signed clinical text is not automatically translated
